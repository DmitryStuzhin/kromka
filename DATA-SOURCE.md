# Источники футбольных данных

## Flashscore-прокси — основной источник календаря и матч-центра

В приложение перенесён способ получения данных из открытого [репозитория f1dos/rpl](https://github.com/f1dos/rpl/tree/main): Python-парсер из `rpl_flashscore_proxy.py` скопирован сюда под именем `flashscore_proxy.py` без изменения его разбора, а отдельный `flashscore-adapter.mjs` сопоставляет ответы с существующими контрактами ТЕМП. Экраны и пользовательские сценарии не заменялись.

Прокси использует Python 3.9+ и стандартную библиотеку Python, без дополнительных пакетов. При `npm start` Node запускает sidecar на `127.0.0.1:8765`. Настройки сервера: `RPL_FLASHSCORE_ENABLED=false` отключает источник, `RPL_FLASHSCORE_AUTOSTART=false` отключает автоматический запуск процесса, а `RPL_FLASHSCORE_PROXY_URL` задаёт адрес уже работающего прокси. Автозапуск разрешён только для локального адреса; для внешнего адреса sidecar нужно запустить отдельно.

Приложение использует прокси-маршруты `GET /api/season`, `GET /api/squads` и `GET /api/match/{id}`. Flashscore в первую очередь поставляет календарь и результаты, ростеры, а также доступные составы, события и статистику матча. Таблица сначала берётся из GOAL API; если GOAL недоступен, она рассчитывается из завершённых матчей Flashscore. Если отдельное поле или весь ответ Flashscore отсутствует, сервер запрашивает соответствующие данные у GOAL.

**Это неофициальный доступ к внутреннему Flashscore feed, а не опубликованный и поддерживаемый Flashscore API.** Успешный ответ или наличие метода в открытом репозитории не подтверждают право на автоматизированный доступ и повторное использование спортивных данных. Feed может измениться, перестать работать или ограничить запросы. В исходном коде референса отдельно указаны кэширование и просьба не делать частых запросов; до публичного/коммерческого запуска владелец приложения должен проверить условия Flashscore и получить нужные разрешения. См. также [условия использования GOAL API](https://goal-api.com/terms): они не передают права на данные Flashscore.

## GOAL API — дополнение и полный резерв

Используется [GOAL API: покрытие РПЛ](https://goal-api.com/coverage/russia-premier-league-api), ID лиги `cmr77dvua00a4rx061d2jre7p`. Ключ `GOAL_API_KEY` хранится только в окружении сервера. При доступном Flashscore GOAL поставляет турнирную таблицу, связывает Flashscore fixture ID с GOAL fixture ID для недостающих ресурсов и live-подписок, а также дополняет сведения в ростерах. Если Flashscore-прокси не отвечает, GOAL становится полным резервным источником календаря, результатов, таблицы, ростеров и доступных данных матч-центра. При выключенном или недоступном GOAL остаются данные Flashscore, но пропадает это дополнение и резерв.

Таблица GOAL запрашивается через `GET /leagues/{id}/standings?season=2026`; резервный календарь — через постраничные `GET /fixtures?leagueId=…&from=…&to=…&limit=100&offset=…` с начала сезона до 30 дней вперёд. Окно дат вычисляется по часовому поясу Москвы. Исторический запрос `GET /leagues/{id}/fixtures?season=2026` ранее возвращал записи разных сезонов и в этой интеграции не используется для календаря. Документация: [API](https://goal-api.com/documentation), [машинно-читаемая справка](https://goal-api.com/llms.txt), [тарифы](https://goal-api.com/pricing), [условия](https://goal-api.com/terms).

Доступность GOAL API проверялась ранее на реальном ключе: снимки 1 и 11 ноября 2026 года показали календарь сезона 2026/27, таблицу из 16 клубов, а для проверенной завершённой игры — HTTP 200 у endpoints событий и статистики. Составы присутствовали в 1 357 из 1 359 записей одного снимка покрытия, но это не обещание состава для каждой будущей игры. Эти проверки — отдельные снимки, не гарантия доступности. Добавленные интеграционные тесты для этой доработки используют локальные mock-серверы, а не live-вызовы к поставщикам.

Для матч-центра используются `GET /fixtures/{fixtureId}/lineups`, `/events` и `/statistics`, но только если fixture ранее получен из календаря РПЛ (`knownFixtures`); неизвестный ID получает 404 до запроса upstream. Если Flashscore не вернул пригодные сведения, данные берутся из GOAL. Кэш GOAL-ростеров — шесть часов, таблицы — 15 минут, истории fixtures — пять минут; события и статистика кэшируются 60 секунд для live-матча, 10 минут для будущего и 24 часа для завершённого. Ответы без данных показываются как отсутствующие — приложение не придумывает состав, цифры или события.

Сервер сохраняет GOAL WebSocket для подтверждённых обновлений счёта, минуты и статуса — максимум 25 активных матчей. Он сопоставляет fixture ID GOAL с ID того же матча в календаре Flashscore перед передачей через SSE. Если нет валидных полей или активных игр, состояние не подменяется. Ранее токен и handshake проверялись, но фактическое end-to-end изменение счёта не было подтверждено, поскольку во время проверки не шёл матч.

Предыдущая ориентировочная оценка в 672 GOAL REST-запроса в сутки относилась к GOAL-only конфигурации с двумя страницами календаря на одно обновление. В этой интеграции GOAL также используется как дополнение, а количество исторических страниц может меняться; поэтому старая оценка не является прогнозом расхода. Проверьте фактические quota-заголовки после запуска и учитывайте, что кэши нескольких процессов не общие.

## API-Football — только портреты игроков

[API-Football squads endpoint](https://www.api-football.com/documentation-v3) остаётся отдельным необязательным резервом только для отсутствующих портретов. `GET /players/squads?team=…` не используется для результатов, таблицы, эмблем, имён, стартовых XI, запасных или формаций. Фото добавляется только при однозначном совпадении с уже полученным игроком. API-ключ `API_FOOTBALL_API_KEY` хранится только на сервере.

Сезонные endpoints бесплатного плана не дают доступ к 2026/27, поэтому используются только текущие squads-ответы. В ранее проверенном ответе Dynamo Moscow было 28 игроков: 26 портретов и два URL с одним общим серым силуэтом. Сервер проверяет содержимое изображения по SHA-256, блокирует известный силуэт и повторяющиеся фото. Данные API-Football кэшируются семь дней на клуб в `.cache/api-football-squads.json`; локальный лимитер оставляет запас от заявленного бесплатного лимита. Если фото не найдено, совпадение сомнительное или изображение не прошло проверку, остаются инициалы.

## Сезонные расчёты и визуальные материалы

Форма, домашне-гостевые показатели и H2H считаются только по завершённым fixtures текущего сезона, которые переданы первичным календарным источником; live-, будущие и некорректные счёты исключаются. Полнота истории оценивается по календарю, показанному приложению: дополнительная история GOAL для сопоставления ID сама по себе не делает Flashscore-календарь полным. H2H относится только к текущему сезону.

Ответ API и доступная картинка не означают передачу прав на эмблему, фотографию или товарный знак. Для GOAL и API-Football здесь не подтверждена лицензия на сторонние изображения; для внутреннего Flashscore feed также не установлено разрешение на повторное использование данных. До публичного или коммерческого релиза проверьте действующие условия и получите необходимые согласия у правообладателей.

# ТЕМП — мобильный MVP для РПЛ

ТЕМП — mobile-first PWA-прототип для болельщиков РПЛ: календарь и матчи, таблица, клубный экран и поиск по клубам. На телефоне сайт можно установить на домашний экран. Это веб-прототип, не нативное приложение в App Store или Google Play.

## Запуск

Требуется Node.js 20 или новее. Для live-WebSocket используйте runtime со встроенным `WebSocket`; без него приложение остаётся на REST-обновлении. Задайте GOAL API key в окружении процесса; резервный портретный источник необязателен:

```bash
GOAL_API_KEY="ваш_GOAL_ключ" API_FOOTBALL_API_KEY="ваш_API_Football_ключ" npm start
```

Откройте `http://localhost:4173`. Без GOAL-ключа приложение работает в явно обозначенном демо-режиме; демо-счёты и матчевые события не являются live-данными. Переменные в `.env.example` — только образец: сервер автоматически не читает файл `.env`.

Оба ключа используются только процессом сервера и не попадают в HTML, JavaScript или ответы API. Не коммитьте файл `.env`, не публикуйте ключи и не передавайте их браузеру.

## Что работает

- Пять основных экранов: «Сегодня», «Матчи», «Избранное», «Таблица», «Мой клуб». На главной показана неделя из семи последовательных дней с переходом к предыдущей/следующей неделе; «Матчи» — отдельный недельный календарь с фильтрами. Дни без матчей остаются пустыми.
- Матч открывается отдельным экраном: турнирная позиция, сезонное сравнение, форма по пяти последним завершённым играм, домашне-гостевые разрезы, очные встречи сезона, составы, события и статистика. Форма и сравнения рассчитываются только по завершённым матчам; если история короче или помечена как неполная, интерфейс не дополняет её демонстрационными результатами.
- Из матча можно перейти в профиль клуба, а из ростера или подтверждённого состава — в профиль игрока. Профиль игрока показывает подтверждённые имя, номер, позицию, возраст и портрет; индивидуальные сезонные голы/матчи/карточки не имитируются, поскольку подключённый GOAL-feed не предоставляет здесь такую статистику.
- Для телефона добавлены короткие переходы между экранами, обновление с индикатором загрузки и скелетоны для запрашиваемых составов; анимации отключаются при системной настройке «уменьшить движение».
- На экранах таблицы и клуба есть простые графики: очки за матч, доли побед/ничьих/поражений, голы за игру и разница мячей. Они рассчитываются только из сыгранных матчей, очков и голов в таблице лиги; демонстрационный срез явно помечен.
- В матч-центре отображаются все парные показатели, которые передал GOAL API: исходная подпись и формат значения (например, проценты или значение с числителем/знаменателем) сохраняются, а числовая часть используется только для сравнительной полосы. Предматчевые нули не показываются как статистика; без данных поставщика экран честно сообщает об их отсутствии.
- PWA-манифест, иконка и service worker; браузерный кэш не сохраняет ответы `/api/*`.
- Матчи и таблица РПЛ загружаются из GOAL API через серверный прокси. Календарный запрос охватывает текущий сезон с 1 июля до 30 дней вперёд и загружает страницы по 100 матчей; признак полноты истории возвращается в интерфейс. Кэш страниц — 5 минут, таблицы — 15 минут. Исключение по эмблемам: актуальный знак «Динамо Москва» закреплён локально; «Динамо Махачкала» сохраняет отдельные эмблему и ID.
- Клиент обновляет календарь и таблицу через REST раз в 5 минут. Когда календарь сообщает об активных играх, сервер подписывается на них одним GOAL WebSocket (до 25 матчей) и передаёт только подтверждённые обновления счёта/статуса/минуты браузеру через SSE. При потере соединения действует повторное подключение и REST остаётся резервом; неоднозначные или отсутствующие значения не подставляются.
- Список игроков клуба загружается при открытии состава через GOAL API. GOAL остаётся главным источником имён, номеров и позиций.
- Если у игрока нет пригодного портрета GOAL, сервер проверяет текущий состав соответствующего клуба через `GET /players/squads?team=…` API-Football. Резерв применяется только к портрету и только при однозначном совпадении игрока; он не заменяет GOAL-имя или номер. API-Football не используется для эмблем, результатов, стартовых XI, запасных или схем.
- API-Football-кеш хранится на сервере в `.cache/api-football-squads.json`, действует 7 дней на клуб и сохраняется между перезапусками. Запрос к этому API делается по требованию — когда в ответе GOAL действительно не хватает портретов. Локальная защита ограничивает расход 80 API-запросами в сутки, оставляя запас от объявленного бесплатного лимита API-Football в 100/сутки. Для нескольких серверных экземпляров нужен общий кеш/лимитер; локальный файл защищает один экземпляр.
- Перед показом резервного фото сервер проверяет HTTPS/CDN-путь и содержимое. Проверенный общий серый силуэт API-Football блокируется; повторяющиеся изображения в одной группе совпадений также отбрасываются. Если картинка не прошла проверку или сопоставление ненадёжно, остаются инициалы.
- Составы, запасные, фотографии игроков и формации матчей по-прежнему загружаются только из GOAL API при открытии матч-центра. Серверный кэш — 10 минут для будущих/live-матчей и 24 часа для завершённых. Приложение не придумывает неподтверждённый XI и не угадывает формацию.
- Схема в карточке матча берётся у GOAL; визуальное поле группирует игроков по указанным позициям, а не утверждает точные координаты каждого футболиста.
- Если ключ отсутствует или провайдер недоступен, интерфейс честно показывает демо-режим либо сохраняет инициалы вместо выдуманной фотографии.

События и статистика матча запрашиваются при открытии через документированные GOAL API endpoints `/fixtures/:id/events` и `/fixtures/:id/statistics`; сервер допускает только fixture ID, предварительно полученные из календаря РПЛ. Кэш событий/статистики — 1 минута для live, 10 минут для будущих и 24 часа для завершённых матчей. Если endpoint пуст или недоступен, экран показывает явное состояние без выдуманных цифр. Очные встречи и домашне-гостевые показатели считаются из тех же завершённых fixtures. Профиль игрока пока не имеет индивидуальной сезонной статистики.

Проверка сохранённого GOAL-ключа 11 ноября 2026 года подтвердила календарь 2026/27, таблицу из 16 клубов и доступность событий/статистики у завершённого матча. WebSocket token и handshake тоже прошли, лимит — до 25 подписок. Во время теста активной игры не было, поэтому фактическое live-изменение счёта не подтверждено; подробные результаты, квота, бесплатные альтернативы и права источников описаны в [DATA-SOURCE.md](DATA-SOURCE.md).

## Покрытие и ограничения

Сезонные endpoints API-Football не дают бесплатному плану доступ к сезону 2026/27. Поэтому интеграция не запрашивает сезонную статистику API-Football: она использует только текущий squads endpoint и только для недостающих портретов. В проверенном ответе Dynamo Moscow API-Football вернул 28 игроков; 26 изображений были портретами, а 2 — одинаковой общей серой заглушкой. Эти заглушки отфильтровываются, но фактическое число замен в каждой команде зависит от совпадения текущего API-Football игрока с ростером GOAL.

GOAL сообщает о составах для 1 357 из 1 359 матчей РПЛ в одном проверенном снимке покрытия; это не гарантия, что состав или формация будут опубликованы к каждому live-матчу. В ранее проверенном ростере Dynamo Moscow GOAL отсутствовали некоторые фото. Даже с резервным источником часть профилей может остаться с инициалами: игрока может не быть в текущем squads-ответе, имя/номер может не совпасть однозначно, CDN может быть недоступен, а типовые силуэты намеренно блокируются.

Идентификаторы 16 клубов API-Football сопоставлены с текущими ID GOAL в `server.mjs`. При смене участников РПЛ этот список нужно обновить. API-Football-кеш и дневной счётчик локальны для одного процесса/файловой системы; кластер или несколько хостов должны использовать общий надёжный storage, иначе защита от повторных запросов между хостами не действует.

**Наличие эмблемы или фотографии в ответе любого из этих API не передаёт проекту права на изображение или товарный знак.** GOAL и API-Football не предоставляют здесь подтверждённую лицензию на клубные эмблемы или фотографии игроков. Перед публичным или коммерческим выпуском получите отдельные разрешения от соответствующих правообладателей; не заявляйте, что картинки свободны для публикации. Массовый скрейпинг сайтов клубов/лиги не используется.

В оформлении используется фотография стадиона «Крестовский ночью» — [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Krestovsky_Stadium_at_night_(cropped).jpg), автор Monoklon, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/); атрибуция указана в интерфейсе.

## Улучшения интерфейса и избранного

- Отдельная нижняя вкладка «Избранное» показывает клубы и матчи, отмеченные пользователем. Выбор сохраняется в `localStorage` текущего браузера и не синхронизируется между устройствами.
- В «Матчах» доступны быстрые фильтры «Все», «Live» и «Избранное», а фильтр клуба покрывает весь текущий список команд. В live-режиме эти же фильтры работают поверх матчей GOAL API.
- Кнопка со звёздочкой у матча сохраняет конкретную встречу; звёздочка в профиле клуба сохраняет сам клуб. Push-уведомления не подключены.
- Создана оригинальная абстрактная эмблема «ТЕМП» без клубной символики; она используется в брендинге и установочных иконках PWA.

При просмотре продукта сверялись публичная [карточка Flashscore в Google Play](https://play.google.com/store/apps/details?id=eu.livesport.flashscoreusa_com&hl=en_US) и открытый [пример РПЛ Arena](https://github.com/f1dos/rpl/tree/main). Код Flashscore-прокси в референсе проверен отдельно: его season-маршрут из sandbox вернул 240 матчей, но используемый feed неофициальный и успешный ответ сам по себе не подтверждает разрешение или лицензию. ТЕМП не включает этот scraper в релизный candidate; пользовательское согласие на доступ не заменяет разрешение правообладателя данных.


### Что взято из референсов и что сознательно не добавлено

Официальная [карточка Flashscore в Google Play](https://play.google.com/store/apps/details?id=eu.livesport.flashscoreusa_com&hl=en_US) описывает live-счёт, избранное и обновления матчей; [страница Flashscore о расширенной статистике](https://www.flashscoreusa.com/news/football-even-more-in-depth-flashscore-expands-match-statistics/6yne1Z8e/) перечисляет дополнительные игровые показатели. В ТЕМП перенесены быстрые фильтры и полка избранного; добавлены сезонные форма, очные встречи и домашне-гостевые разрезы из уже загруженной истории, а матчевые события и показатели запрашиваются у GOAL API.

Открытый [RPL Arena пример](https://github.com/f1dos/rpl/tree/main) включает страницы клубов/игроков, матч-центр, избранное и сравнение. В ТЕМП сравнение расширено сводными показателями таблицы и разрезами сезона, а очные встречи строятся из подтверждённых завершённых fixtures. Примерный репозиторий использует неофициальный Flashscore feed; он проверен технически, но не перенесён из-за неясных условий доступа и прав на данные. Датированные JSON-снимки из референса также не копируются.

# Проверки перед публичным релизом

Это release candidate, а не утверждение о полном коммерческом допуске. Пункты ниже отделяют проверенную функциональность от решений и проверок, которые ещё нужны до публикации.

## Уже проверено в этом кандидате

- `npm run check` проходит, а `npm test` покрывает календарь, таблицу, избранное, сравнение, матчевые детали, нормализацию статистики, роуты и live-stream.
- Секреты провайдеров читаются из переменных окружения сервера; в клиентский код и ответы `/api/status` ключи не включаются.
- Идентификаторы матчей проверяются по календарю РПЛ до upstream-запросов событий, статистики и составов.
- Матчевая статистика отображает значения так, как их передал GOAL API; числовая часть применяется только для сравнительной шкалы. Неполные пары значений отбрасываются, отсутствующие значения не заменяются нулями.
- Flashscore scraper, его недокументированная feed-подпись и исторические JSON-снимки не включены. Аналог использовал endpoint `flashscore.ninja` с `x-fsign` и содержал подсказку про VPN; пользовательское разрешение на изучение референса само по себе не устанавливает разрешение поставщика на автоматизированный сбор или повторное использование данных.

## Обязательные проверки до публичного запуска

- **Права на спортивные данные и изображения.** Получить разрешения/подтверждение условий для публичного или коммерческого использования данных и медиа от GOAL API, API-Football и правообладателей эмблем/фотографий. Ответы API сами по себе такую лицензию не дают. См. [MEDIA-SOURCES.md](MEDIA-SOURCES.md) и [DATA-SOURCE.md](DATA-SOURCE.md).
- **Источник Flashscore.** Если расширенные поля, которых нет в GOAL, необходимы продукту, сначала получить письменное разрешение поставщика или договориться с лицензированным провайдером с документированным API и правом повторной публикации. Не подключать неофициальную ленту, не имитировать клиентские подписи и не обходить географические/технические ограничения.
- **Секреты и хостинг.** Задать `GOAL_API_KEY` в secret manager окружения, проверить разрешённый для ключа `GOAL_RPL_LEAGUE_ID`, HTTPS, проксирование SSE и доступность сервера из целевых регионов. `API_FOOTBALL_API_KEY` необязателен и используется только для портретов.
- **Квота и масштабирование.** Для проверенного GOAL-аккаунта подтверждалась квота 1 000 REST-вызовов в сутки и WebSocket до 25 подписок; базовая оценка при одном экземпляре — около 672 REST-вызовов/сутки до дополнительных запросов матчевых деталей. На запуске наблюдать за фактическими quota-заголовками. Процессные кеши/лимитеры не координируются между экземплярами: сначала запускать один экземпляр либо добавить общее хранилище и распределённое ограничение запросов.
- **End-to-end live-проверка.** Текущая проверка подтверждала получение WebSocket token и handshake, но не изменение счёта в реальной live-игре. Проверить событие на разрешённой тестовой/живой игре, переподключение, SSE до браузера и резервное REST-обновление; не объявлять live-доставку без этого теста.
- **Бренд и продуктовые тексты.** Интерфейс и иконки пока маркированы «ТЕМП», тогда как репозиторий называется `kromka`. Утвердить финальное имя, иконку и тексты до выпуска, не считая имя репозитория достаточным решением о бренде.
- **Проверка целевых устройств.** Пройти установку PWA и ключевые сценарии на реальных мобильных браузерах iOS/Android; проверить TLS, обновление service worker и доступность `/api/*` через выбранный reverse proxy.
- **Политика продукта.** Перед открытием для пользователей опубликовать необходимые контакты, политику конфиденциальности и условия использования, описать локальное хранение избранного и процесс обработки пользовательских обращений. Вход и push-уведомления сейчас не реализованы.

## Источники данных в приложении

| Данные | Источник | Ограничение |
|---|---|---|
| Календарь, счёт, таблица, ростеры, составы, события и доступная статистика | GOAL API | Покрытие и частота полей зависят от матча и аккаунта; статистика не дополняется синтетическими значениями. |
| Резервные фото игроков | API-Football, только текущие squads | Вызывается по требованию для отсутствующих фото GOAL, после однозначного совпадения; не используется для матчей или сезонных показателей. |
| Flashscore | Не подключён | Неофициальный proxy из аналога исключён до подтверждения правомерного доступа и лицензии на публикацию. |
| Демо-режим | Встроенный тестовый срез | Всегда должен оставаться явно помеченным как демо и не выдаваться за live-данные. |

# Эмблемы, портреты и составы РПЛ: источники и ограничения

## Эмблемы клубов

Для клубов используются эмблемы GOAL API: `team.badge`/поля эмблем в fixtures и standings, с одним проверенным исключением. **«Динамо Москва»** использует актуальную официальную эмблему — синюю «Д» с двумя золотыми звёздами, а не старый ромб из GOAL. Файл хранится локально в `assets/club-crests/dynamo-moscow.svg`; [официальная страница символики](https://fcdynamo.ru/club/symbols/), [исходный SVG](https://static.fcdm.ru/seo/fcdm.svg). Эта привязка имеет приоритет при каждом API-обновлении. Московский ID GOAL — `cmr7uolsy8mghrx06jog9s5dt`; отдельный ID «Динамо Махачкала» — `cmr7uolt08mgjrx06xj1x745j`, его эмблема GOAL `6210_dinamo-makhachkala.jpg` не заменяется.

Официальный сайт клуба сохраняет все права на материалы; наличие локального файла не является лицензией на публичное или коммерческое использование. API-Football не используется как источник эмблем.

## Портреты игроков

GOAL API остаётся первым источником портрета (`image` в ростере клуба и `playerImage` в составе матча). Только если GOAL не прислал пригодное изображение, сервер может найти фото соответствующего игрока в текущем API-Football `players/squads`-ответе. Резерв не меняет список, имя, номер, позицию или клуб игрока из GOAL.

Сопоставление нормализует акценты и кириллическую транслитерацию и принимает только однозначное совпадение полного имени либо совпадающих первых инициалов с фамилией. Один лишь номер, похожая фамилия или короткое имя без фамилии не считаются достаточным доказательством. Резервные URL разрешены только с `media.api-sports.io/football/players/{id}.png`. Сервер скачивает портрет-кандидат и сравнивает содержимое с контрольной суммой проверенного серого силуэта API-Football. Известная заглушка и одинаковые изображения разных кандидатов отбрасываются. Если проверка или сопоставление не проходят, интерфейс показывает инициалы, а не случайное лицо.

Проверенный текущий состав Dynamo Moscow в API-Football содержал 28 игроков: у 26 URL были реальные портреты, два URL отдавали один и тот же серый силуэт. Этот результат не означает, что все 26 фото совпадут с текущим ростером GOAL: составы и написание имён двух провайдеров отличаются. Кеш API-Football живёт семь дней на клуб, сохраняется между рестартами на диске сервера, обновляется по требованию и защищён локальным потолком 80 API-запросов в сутки. Free-план API-Football указывает 100 запросов в день; в этом MVP сезонные API не вызываются. Локальный счётчик не видит запросы с того же ключа вне этого экземпляра сервера, поэтому внешний usage и несколько хостов требуют общего лимитера.

## Составы и формации

Клубный ростер, подтверждённый стартовый XI, запасные и formation/system в матч-центре приходят из GOAL API. API-Football используется только для портрета участника уже полученного состава GOAL. Если GOAL пока не опубликовал lineup или схема отсутствует, интерфейс сообщает об этом явно; приложение не выдумывает XI и расстановку.

По снимку покрытия GOAL, использованному в документации проекта, lineups были доступны для 1 357 из 1 359 матчей. Это показатель покрытия поставщика в тот момент, а не обещание для каждого матча. В ранее проверенной игре в составе стартующих и запасных было 43 фото на 45 записей; в проверенном live-матче lineup пока был пуст. Реальные пропуски фото могут оставаться, если игрок не входит в текущий API-Football squads-ответ, имя сопоставить нельзя или CDN не отдаёт проверенный портрет.

## Права и распространение

**Получение файла через API не передаёт право на клубную эмблему, фотографию футболиста или товарный знак.** Условия GOAL предупреждают о правах третьих лиц; API-Football в этой интеграции также не предоставляет подтверждённой лицензии на сторонние фото/эмблемы. Для публичного или коммерческого продукта нужно отдельно согласовать права с клубами, лигой, фотографами/агентствами и проверить условия провайдеров. Документация: [GOAL API](https://goal-api.com/documentation), [условия GOAL](https://goal-api.com/terms), [API-Football](https://www.api-football.com/documentation-v3).

Массовый скрейпинг сайтов РПЛ или клубов не используется. Для законного публичного пакета следует запросить лицензированный media kit у лиги/клубов и хранить письменные разрешения, ограничения по территории, сроку и способу использования.

[Официальные условия API-Football, Service & data / Data/Logos/images](https://www.api-football.com/terms) прямо указывают, что поставщик не владеет этими визуальными активами, не выдаёт лицензию на публикацию и оставляет получение необходимых разрешений пользователю. В [GOAL, разделах 6–7](https://goal-api.com/terms), установлено аналогичное ограничение.
